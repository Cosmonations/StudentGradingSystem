## About This Project
Early into my C++ Journey, I made v1.0 to practice iostream and conditionals. 
Later, I made v2.3 to experiment with integrating for loops, while loops and conditionals. 
Lastly, I made v3.2 to solidify my understanding of fstream
## How it works
- For v1.0, you simply enter the full name and score, then a letter Grade is generated
- For v2.3, you enter the fullname, number of subjects and the score in each subject and then generates a full report, including a letter grade
- v3.2 works the same as v2.3 except the essential information of the final report is also printed out onto a csv file
